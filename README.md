
# AI Internship Job Radar

A free Python job-alert system that monitors RSS job feeds,
filters AI/ML and Data Science opportunities, removes duplicates
and sends Gmail notifications.

## Technologies
- Python
- RSS / feedparser
- Gmail SMTP
- GitHub Actions
- JSON state storage

## Running locally
1. Install dependencies from requirements.txt.
2. Configure .env using .env.example.
3. Add RSS feeds to config.json.
4. Run python main.py.
